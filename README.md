# 🌱 AgriAssist

AgriAssist is an AI-powered smart agriculture web application designed to help farmers make better farming decisions.

## 🚀 Features

- 🌦️ Weather Information
- 🌱 Soil Analysis
- 🌾 Crop Recommendation
- 💹 Market Price Updates
- 🔐 User Login System
- 🌍 Simple and User-Friendly Interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Java

## 🎯 Objective

The objective of AgriAssist is to support farmers by providing essential agricultural information in one platform, enabling informed decisions and improving productivity.
